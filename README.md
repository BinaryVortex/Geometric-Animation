# Geometric Animation

A collection of interactive geometric animations built with HTML, CSS and JavaScript.

![Demo screenshot](./Screenshot%202024-08-22%20140739.png)

Live demo

- Open `index.html` in your browser to view and interact with the animation.

Overview

This repository contains a small, self-contained web project that demonstrates animated geometric patterns and interactions using modern CSS and vanilla JavaScript. It is intended as a visual experiment and a learning resource for CSS animations, transforms, and canvas/DOM motion.

Files

- `index.html` — Project entry point.
- `style.css` — Styling and animation rules.
- `script.js` — JavaScript used to animate and control the scene.
- `Screenshot 2024-08-22 140739.png` — Screenshot of the animation shown above.

Features

- Smooth, GPU-friendly CSS animations.
- JavaScript-driven motion and interaction.
- Minimal dependencies — no build step required.

Technologies

- HTML
- CSS (transforms, animations)
- JavaScript (ES6)

How to use

1. Clone the repository:

   git clone https://github.com/BinaryVortex/Geometric-Animation.git

2. Open `index.html` in your favorite browser.

Customization

- Edit `style.css` to change colors, timing, and animation easing.
- Edit `script.js` to change motion parameters, add new shapes, or modify interaction logic.
